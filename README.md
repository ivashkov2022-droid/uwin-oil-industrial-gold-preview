# UWIN OIL — preview

Публичная версия для согласования оптимизированной кодовой копии исходной страницы UWIN OIL.

Предпросмотр: `https://ivashkov2022-droid.github.io/uwin-oil-preview/`.

- визуальная структура и тексты сохранены по исходной Tilda-странице;
- повторяющиеся мобильные и десктопные блоки заменены единой адаптивной вёрсткой;
- поисковая индексация предпросмотра запрещена;
- canonical указывает на основной домен `https://uwingroup.ru/`;
- Яндекс Метрика отключена, чтобы предпросмотр не загрязнял статистику;
- формы работают в демонстрационном режиме и не отправляют персональные данные;
- текущая Tilda-страница, REG.RU и основной домен этой версией не затрагиваются.

Рабочие исходники, серверная обработка форм и история разработки хранятся отдельно в закрытом репозитории.
